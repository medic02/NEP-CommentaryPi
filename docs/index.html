Kommandoer

🚀 Installasjon
Ny Satellite Pi (full install)
curl -fsSL https://raw.githubusercontent.com/medic02/NEP-CommentaryPi/main/install.sh | bash
Companion Pi / kun Health API
curl -fsSL https://raw.githubusercontent.com/medic02/NEP-CommentaryPi/main/install-health.sh | bash
Aktiver SSH på SD-kort ⚠️ Kjøres på Mac, ikke Pi
touch /Volumes/bootfs/ssh
Tailscale – logg inn
sudo tailscale up
Tailscale – aksepter subnet routes
sudo tailscale set --accept-routes=true --accept-dns=false
Sett tidssone (Norge)
sudo timedatectl set-timezone Europe/Oslo
🔄 Oppdatering
Oppdater Pi (health, dashboard, watchdog)
curl -fsSL https://raw.githubusercontent.com/medic02/NEP-CommentaryPi/main/scripts/nep-update.sh | bash
Oppdater Failover-script
curl -fsSL https://raw.githubusercontent.com/medic02/NEP-CommentaryPi/main/scripts/nep-ts-failover.sh | sudo tee /usr/local/sbin/nep-ts-failover.sh > /dev/null
Oppdater Stream Deck-patch
curl -fsSL https://raw.githubusercontent.com/medic02/NEP-CommentaryPi/main/scripts/patch-satellite.py -o /tmp/patch-satellite.py && sudo python3 /tmp/patch-satellite.py
⚙️ Tjenester
Restart Satellite
sudo systemctl restart satellite
Restart alle NEP-tjenester
sudo systemctl restart nep-health && sudo systemctl restart satellite
Status
systemctl status nep-health satellite nep-ts-failover.timer
Endre Pi-navn
sudo nano /etc/systemd/system/nep-health.service # Endre: Environment="NEP_ID=Satellite Pi X" sudo systemctl daemon-reload && sudo systemctl restart nep-health
📋 Logging
Failover-logg (live)
journalctl -t nep-ts-failover -f
Failover-logg (siste 50)
journalctl -t nep-ts-failover -n 50
Satellite-logg
journalctl -u satellite -n 50
